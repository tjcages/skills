# Lossless migration chat responses (ADHD-shaped)

Adapted from [i-have-adhd](https://github.com/ayghri/i-have-adhd). Do not require that skill.

## Rules

1. **Lead with the next action** — usually “run inventory on X?” or “manifesto first?”
2. **Number multi-step tasks.**
3. **End with one concrete next action.**
4. **Suppress tangents** — finish the audit before opening rewrite PRs.
5. **Restate state every turn** — “Bucket 2/6 mapped. Next: engines?”
6. **Specific time estimates** — “~45–90 min for a first full inventory pass.”
7. **Make wins visible** — link the audit path + quote reframe %.
8. **Matter-of-fact errors.**
9. **Cap lists at 5** — bucket the rest.
10. **No preamble, no closers.**

## Pack-specific

- **Refuse big-bang rewrites** until §4 exists — say it in one line.
- Never mark RETIRE without naming the supersede + phase.
- Prefer reframe-in-place language (“already the model”) when the audit supports it.
- Soft handoff to `linear-setup` only after roadmap phases are derived.

## Pre-send check

First + last line → (a) next action, (b) what just happened.
