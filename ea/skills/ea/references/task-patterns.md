# Small delegation contracts

**Navigation:** “Open the Composer documentation; success is its exact URL and
heading.” Offer only currently visible, uniquely identified links. A known exact
link is cheaper to click directly.

**Classification:** “Route this redacted report to billing, account, technical,
or supervisor review.” Use descriptions that discriminate the categories. JEV
returns a category ID, not a rewritten report. The supervisor verifies uncertain
cases; categorization alone never sends a message or edits a record.

**Capture recovery:** “Tests passed; recording failed to create a file.” Offer
retry once only if the capture command is idempotent and its failure is known;
otherwise inspect or escalate. Success requires an actual playable artifact.

**Bulk cleanup:** File renaming, JSON validation, inventory generation and link
checks belong in a script. Dry-run mutations when needed and verify resulting
files. Do not pay JEV to repeat deterministic transformations.

**Writing/code:** Route back to the supervising agent or a separately configured
capable delegate. Never attempt to make Choice responses stand in for generation.
Keep payloads small and independent; pass only the applicable task instructions.
