# Practical EA requests

These are requests to the host agent, not standalone commands or guarantees of unattended operation.

## Find broken catalogue links

> Use EA to check every external link on /components/buttons. Return the broken URL, its page location, and HTTP status. Leave working links out.

A script checks links. Astra investigates redirects or ambiguous failures; JEV is unnecessary.

## Find the errors worth investigating

> Use EA to group this redacted build log into duplicate errors, warnings, and likely root causes. Show me the three failures to investigate first, with their original line numbers.

Tools extract and deduplicate. JEV classifies compact excerpts; Astra diagnoses causes against the original log.

## Navigate without repeated reasoning

> Use EA to open the Composer entry in this catalogue and find its implementation section. Stop when the heading and code are visible; report the final URL.

The host reads the page and executes navigation. JEV chooses only when visible targets are ambiguous. The host verifies the destination.

## Prepare a recording batch

> Use EA to check these six component recordings for missing files, incorrect dimensions, and durations over 12 seconds. Return a retake list. Leave visual quality review to Astra.

Media tools inspect metadata without model calls. JEV does not watch video or judge animation quality.

## Choose the right skill

> Use EA to find one reviewed tool for verifying whether a cited page supports a claim. Prefer my existing Cloudflare setup. Explain any installation or compatibility gaps.

A local catalogue query produces candidates. JEV can rank them; Astra checks the selected tool’s actual capabilities. No automatic installation.

## Review catalogue updates

> Use EA to compare today’s source revisions with the last check. Flag changes that affect installation, supported providers, or safety limits. Keep unchanged entries quiet.

The watcher fetches metadata. JEV classifies relevant diffs; Astra reviews updates before changing recommendations.
