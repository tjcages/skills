# Install — manifesto

```bash
npx skills add tjcages/manifesto-skill -g -a '*' -y
```

Copies `manifesto` into `~/.claude/skills`, `~/.cursor/skills`, `~/.codex/skills`, `~/.agents/skills`.

## First use

In Agent chat:

```text
Does this product have a North Star? Run manifesto.
```

Or: write / audit a manifesto before `linear-setup`.

Template: `shared/north-star.template.md` → product `docs/north-star.md` or `docs/manifesto.md`.

Site: [offbr.co/skills/manifesto](https://offbr.co/skills/manifesto)
