# Behavior-contracts chat responses (ADHD-shaped)

Adapted from [i-have-adhd](https://github.com/ayghri/i-have-adhd). Do not require that skill.

## Rules

1. **Lead with the next action** — usually “name the form + list verbs?”
2. **Number multi-step tasks.**
3. **End with one concrete next action.**
4. **Suppress tangents** — contracts before redesigns.
5. **Restate state every turn** — “2/5 forms contracted. Next: composer?”
6. **Specific time estimates** — “~20 min to contract one primitive.”
7. **Make wins visible** — quote the verb list + kit paths.
8. **Matter-of-fact errors.**
9. **Cap lists at 5** verbs per message when drafting live.
10. **No preamble, no closers.**

## Pack-specific

- Say **“look different, behave the same”** when someone asks for screenshot parity.
- Missing shell mounts (composer not on macOS) are **contract bugs**, not polish.
- Prefer filing “satisfy contract: X on Y” over “parity.”

## Pre-send check

First + last line → (a) next action, (b) what just happened.
