# Apple Native

A lightweight agent skill for native iOS product work. Guidance, component records,
public source downloads, and retrieval tools live at https://native.offbr.co.

```sh
npx skills add tjcages/skills --skill apple-native
```

Invoke `$apple-native`, or ask for native SwiftUI work. The skill retrieves relevant
records instead of loading an entire component library. No private repository access
is required for the public catalogue. Private/licensed implementations remain unavailable.

Examples:
- “Use apple-native to adapt this web checkout to iPhone.”
- “Find the existing glass button implementation and wire it to this action.”
- “Audit this composer for interrupted sends and draft recovery.”

Version 0.1.0: public retrieval verified; not a universal production certification.
Use `apple-native` for new installations and repository instructions, retaining
intentional app-specific contracts.
