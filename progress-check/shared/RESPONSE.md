# Progress Check responses

## Rules

1. Lead with changed state, not an announcement that work continues.
2. Use at most three numbered items: completed, current, and next or blocked.
3. Include concrete evidence for completed work.
4. Keep one overall progress bar at the end.
5. Do not post when the percentage and material state are unchanged.
6. Report blockers matter-of-factly with the action needed to clear them.
7. Report completion immediately and use 100% only after every gate passes.
8. Do not add a closing pleasantry or ask a generic follow-up question.

## Example

1. The API contract and migration now pass their focused checks.
2. Deployment verification is active.
3. Next: confirm the preview route returns the new response shape.
