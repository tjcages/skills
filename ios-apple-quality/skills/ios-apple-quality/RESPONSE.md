# Response shape

When this skill is active:

1. Name the platform and navigation paradigm you assumed.
2. Cite HIG / Liquid Glass rules you applied (one line each).
3. If you invented UI, say which Mobbin-class pattern you matched — or that you skipped Mobbin and why.
4. Call out a11y and availability fallbacks explicitly.
5. Prefer diffs and screenshots over prose. Keep status short.
